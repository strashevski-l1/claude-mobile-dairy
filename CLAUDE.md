# Инструкции для Claude

Этот репозиторий — дневник сессий работы с Claude Code. Основной файл — `README.md`.

## Структура README.md

1. **Раздел "Задачи"** — самый верх файла. Список актуальных задач в виде чекбоксов (`- [ ]` / `- [x]`). Здесь всегда держим то, что нужно сделать дальше.
2. **Раздел "Сессии"** — ниже задач. Хронологический конспект всех сессий, сгруппированный по датам (заголовок `### YYYY-MM-DD`). Новые даты добавляются в конец файла (сверху вниз — от старых к новым), внутри одной даты может быть несколько сессий.

## Правила ведения записей о сессиях

- В конце каждой сессии добавляй краткую запись под сегодняшней датой: что делали, что изменили, что решили, что осталось.
- **Жёсткое ограничение: не более 100 слов на одну сессию.** Если сессия большая — выделяй только суть, без деталей и кода.
- Не переписывай и не сокращай задним числом уже сделанные записи прошлых сессий.
- После записи сессии сверяй раздел "Задачи": отмечай выполненное (`[x]`), добавляй новые задачи, если они появились по ходу сессии.
- Пиши по-русски, лаконично, без воды.
