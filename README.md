# CySEC study notes — учебный мануал

Конспект для подготовки к экзаменам **CySEC Advanced, Basic и AML**: 163 темы по 20 предметам. В каждой теме:
короткий ответ, таблица ключевых фактов, разбор, глоссарий, «Exam material vs Current law», типичные ошибки и ссылки на закон.

**[📚 Полное оглавление всех тем](cysec-study-notes/contents.md)** · [Главная мануала](cysec-study-notes/) · [Advanced](cysec-study-notes/advanced.md) · [Basic](cysec-study-notes/basic.md) · [AML](cysec-study-notes/aml.md)

## Как заниматься

1. Выберите экзамен ниже и откройте главу — там список тем и таблица «The numbers to know».
2. Читайте темы по порядку: внизу каждой есть переход «Next topic →» и «Related topics».
3. Перед экзаменом повторите разделы **Key facts** и **Common mistakes**, а в блоках «In the exam» — что спрашивает экзамен и что действует сейчас.
